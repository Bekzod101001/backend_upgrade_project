## Правила

1. Один курс до конца. Не переключаюсь на другой, пока не закончу этот.
2. Каждый урок = один файл в `lessons/` по шаблону [`_template.md`](_template.md).
3. Перед уроком: 10–15 минут пишу свой вариант решения (если урок про design-задачу).
4. В начале каждой сессии: 5 минут по памяти вспоминаю прошлый урок, без подсказок.
5. Урок без заполненных «Что я упустил» и «Объяснение за 3 минуты» не считается пройденным.
6. В checkpoint-день (каждый 7-й) рисую по памяти одну систему из пройденных за неделю и объясняю её вслух.

Имя файла: `lessons/NN-short-topic.md` (например, `lessons/04-rate-limiter.md`).
